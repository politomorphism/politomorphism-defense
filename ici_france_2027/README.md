# ICI known-groups test — French presidential campaign 2027

Pre-registered test of whether ICI (Intra-contextual Incoherence, the framing component of
SRM drift) registers ideological framing: for the same candidate and period, do headlines
from opposite camps (Libération, L'Humanité, Mediapart vs. Le Figaro, CNews, Valeurs
actuelles) diverge more than headlines from two outlets of the same camp?

Status: pre-registration version 1, written 18 November 2026, to be filed on OSF before
1 December 2026. No data for this study have been collected.
